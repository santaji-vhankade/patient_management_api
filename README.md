# Patient Management System API (FastAPI)

This is a REST API built using FastAPI to manage patient records. It supports creating, viewing, updating, deleting, and sorting patient data. The BMI and health verdict are computed dynamically based on height and weight.

---

## Features

- Create a new patient
- View one or all patients
- Update patient details
- Delete a patient record
- Sort patients by height, weight, or BMI
- Compute BMI and health status automatically

---

## Requirements

- Python 3.8 or higher
- FastAPI
- Uvicorn
